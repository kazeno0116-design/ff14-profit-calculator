PARTY TARGET MACRO

パーティーリスト対象スキル用
マクロ作成ツール

単体の対象指定マクロに加えて、事前アクションのあとにパーティーリスト指定アクションを実行する連続マクロも作成できます。

マクロを作る

事前アクションは任意です。空欄なら従来どおり <1> ～ <8> を直接指定する単体マクロを生成します。

PvE / PARTY
対象指定アクションより先に自分が使用するアクション。不要なら空欄にしてください。
事前アクションがある場合のみ /wait を挿入します。
ゲーム内のアクション名をそのまま入力してください。
対象指定アクションを入力して「マクロを生成する」を押してください。

使い方

  1. 前処理が必要なら事前アクションを入力します。不要なら空欄で構いません。
  2. 対象指定アクションを入力し、マクロを作りたいパーティーリスト番号を選びます。
  3. 生成後、各番号の「コピー」を押し、FF14のユーザーマクロへ貼り付けます。
  4. ホットバーへ配置し、実戦投入前に対象と発動タイミングを確認してください。
連続マクロの例

/ac "迅速魔" → /wait 1 → /ac "レイズ" <4> のように生成できます。待機時間は0～3秒から変更できます。

補足

<1>～<8> はパーティーリスト上からの順番を指定します。アクションによっては対象指定できないものがあります。また、マクロ化したアクションは通常のアクション操作と挙動が異なるため、用途に応じて使い分けてください。
