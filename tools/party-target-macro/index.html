PARTY TARGET MACRO

パーティーリスト対象スキル用
マクロ作成ツール

アクション名を入力し、対象にしたいパーティーリスト番号を選ぶだけで、番号ごとのマクロをまとめて作成できます。

マクロを作る

パーティーリストの <1> ～ <8> を直接指定するマクロを生成します。

PvE / PARTY
ゲーム内のアクション名をそのまま入力してください。
アクション名を入力して「マクロを生成する」を押してください。

使い方

  1. ゲーム内で使いたいアクション名を入力します。
  2. マクロを作りたいパーティーリスト番号を選びます。
  3. 生成後、各番号の「コピー」を押し、FF14のユーザーマクロへ貼り付けます。
  4. ホットバーへ配置し、実戦投入前に対象と発動を確認してください。
補足

<1>～<8> はパーティーリスト上からの順番を指定します。アクションによっては対象指定できないものがあります。また、マクロ化したアクションは通常のアクション操作と挙動が異なるため、用途に応じて使い分けてください。
