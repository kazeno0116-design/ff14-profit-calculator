PARTY TARGET MACRO

パーティーリスト対象スキル用
マクロ作成ツール

複数のアクションを好きな順番で追加し、パーティーリスト対象を含む連続マクロを作成できます。

マクロを作る

アクションを必要な数だけ追加してください。各行ごとに対象と待機時間を設定できます。

PvE / PARTY
アクションを入力して「マクロを生成する」を押してください。

使い方

  1. 各行にアクション名を入力します。
  2. その行を「自分に使用」するか「選択したパーティー番号に使用」するか選びます。
  3. 必要なら待機時間を設定します。待機は同じ行の末尾に <wait.1> の形で入ります。
  4. 「アクションを追加」で3種類以上の連続マクロにもできます。
  5. 対象番号を選んで生成し、番号ごとのマクロをコピーします。
例

/ac "迅速魔"
/ac "レイズ" <4>
/ac "アクアヴェール" <4> <wait.1> のように、複数種類を順番に並べられます。

補足

<1>～<8> はパーティーリスト上からの順番です。15行を超える構成は生成できません。
