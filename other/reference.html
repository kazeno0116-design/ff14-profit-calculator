BEGINNER TERMS

初心者向け情報で出てくる用語

初心者向けページで意味が分かりにくくなりやすい用語を、もう少し詳しく説明しています。本文中の用語リンクから、この位置へ直接移動できます。

エーテライト各地にある大きなクリスタル。一度「交感」したエーテライトはテレポの行き先として利用できます。都市内の小型エーテライトは、同じ都市の中を移動するための転送網として使います。
テレポ交感済みのエーテライトへ移動するアクション。マップやテレポ一覧から目的地を選んで移動します。通常はギルを消費しますが、お気に入り登録や各種割引・無料設定などで費用を抑えられる場合があります。
デジョン設定したホームポイントへ戻るアクション。テレポと違ってギルは消費しません。帰還先はホームポイントとして設定したエーテライトで、使用後は再使用まで待ち時間があります。
ホームポイント戦闘不能時やデジョンで戻る帰還先。エーテライトで設定できます。テレポのお気に入りとは別の仕組みなので、ストーリーを進めている地域や戻ることが多い都市を設定すると分かりやすくなります。
ホットバーアクションや機能を登録してすぐ使えるようにする操作欄。戦闘アクションだけでなく、テレポ、デジョン、マウント、エモート、アイテム、ギアセットなども登録できます。位置・大きさ・形・表示数はHUDレイアウトなどから調整できます。
ギアセット現在の装備一式をセットとして保存する機能。ジョブごとの装備を登録しておくと、セットを選ぶだけでまとめて着替えられます。複数ジョブを遊ぶようになると、装備を一つずつ選び直す手間を減らせます。
クラス / ジョブキャラクターが切り替えて遊べる戦闘・製作・採集の種類。初期から選べる戦闘クラスの一部は、条件を満たすと対応するジョブへ発展します。追加された戦闘職にはクラスを経由せずジョブとして開放されるものもあります。レベルは基本的にクラス・ジョブごとに管理されます。
ロールパーティ内で担当する大きな役割。戦闘では主にタンク・ヒーラー・DPSに分かれます。タンクは敵の攻撃を受け、ヒーラーは回復と支援、DPSはダメージを与えることを中心に担当します。コンテンツではロールごとの人数構成が決まっている場合があります。
敵視敵が誰を攻撃対象として優先するかを表す仕組み。パーティでは主にタンクが敵視を集め、敵の攻撃を引き受けます。敵視の状態はパーティリストや敵視表示などから確認できます。
リミットブレイク（LB）パーティで共有するゲージを使う特殊アクション。ロールによって効果が異なり、攻撃・回復・防御などに使われます。自分専用のゲージではなくパーティ全体で共有するため、使いどころはコンテンツや状況によって変わります。
アイテムレベル（IL）装備の強さを示すための数値。キャラクターレベルとは別の数値です。同じ装備可能レベルでもアイテムレベルが異なる場合があり、コンテンツによっては平均アイテムレベルが参加条件になります。
マテリア装備へ付けて一部の能力値を追加できるアイテム。装備やマテリアの種類によって装着できる能力や上限が異なります。序盤では必須ではありませんが、装備を細かく調整したい段階で使う要素です。
錬精度装備を使うことでたまっていく値。錬精度が100％になった対応装備は「マテリア精製」を行えます。装備を使い続けることで自然に上がっていくため、序盤は数値があることを知っておく程度でも問題ありません。
コンテンツファインダー（CF）ダンジョンや討滅戦などへ参加申請するための機能。遊びたいコンテンツを選んで申請すると、必要なロールのプレイヤーを自動で探してパーティを組みます。対応コンテンツでは人数や参加条件も画面で確認できます。
ロット / NEED / GREED / PASSパーティで入手した戦利品の分配方法。NEEDは条件を満たして装備できる場合などに選べ、GREEDはNEEDできない場合でも欲しいとき、PASSは不要なときに選びます。複数人が希望した場合はロット値で取得者が決まります。
パーティ募集目的や条件を書いて、一緒に遊ぶメンバーを自分で募集する機能。コンテンツファインダーの自動マッチングとは違い、「初見」「練習」「周回」など目的を指定して集められます。募集文の条件を確認して、自分の目的に合う募集へ参加します。
制限解除通常の参加条件の一部を外してコンテンツへ突入する設定。主に過去コンテンツの攻略や周回などで使われます。通常攻略とはレベルや人数の条件が変わるため、初めて通常の攻略を体験したい場合とは用途が異なります。
コンテンツサポーター対応コンテンツをNPCメンバーと攻略できる機能。他プレイヤーとの自動マッチングを使わず、自分のペースで進めたいときに選べます。すべてのコンテンツが対応しているわけではなく、対応状況はコンテンツごとに異なります。
アーマリーチェスト武器や防具などの装備品を入れる専用の収納場所。取得した装備は基本的に部位ごとのアーマリーチェストへ入ります。複数のクラス・ジョブを遊ぶと装備が増えるため、所持品とは別にここも整理すると管理しやすくなります。
チョコボかばん通常の所持品とは別に使える追加の収納場所。バディ機能の開放後に利用できます。すぐには使わない素材や予備品などを分けて保管できますが、利用できる場面には制限があります。
グランドカンパニーストーリー中に所属する3都市の組織。黒渦団・双蛇党・不滅隊のいずれかへ所属します。階級、軍票、グランドカンパニー関連のクエストや機能などがあり、マイチョコボ取得にも関係します。
バディマイチョコボをフィールドで仲間として呼び出す機能。開放すると、チョコボを戦闘の補助役として呼び出せます。バディ開放とあわせてチョコボかばんも利用できるようになります。
リテイナーアイテム保管やマーケット出品などを任せられるNPC。ゲームを進めると雇用でき、所持品とは別の保管場所として使えます。マーケットへの出品はリテイナーを通して行い、開放後はリテイナーベンチャーも依頼できます。
リテイナーベンチャーリテイナーを探索やアイテム調達へ送り出す仕組み。依頼内容に応じて一定時間後にリテイナーがアイテムを持ち帰ります。リテイナーのクラス・ジョブやレベルなどによって依頼できる内容が変わります。リテイナーを雇った直後から自動で使える機能ではなく、関連クエストの開放が必要です。
武具投影 / ミラプリ装備の性能を変えず、見た目だけを別の装備へ変更する機能。日本語の正式な機能名は「武具投影」で、プレイヤー間では「ミラプリ」と呼ばれることが多いです。見た目に使う装備には、装備条件など武具投影固有のルールがあります。
ミラージュドレッサー見た目用に使いたい対応装備を保管・管理する設備。収納した装備はミラプリに利用でき、ミラージュプレートのコーディネート作成にも使います。通常の所持品やアーマリーチェストとは用途が異なる、見た目管理向けの収納です。
ミラージュプレート複数部位の見た目をコーディネートとして保存しておく機能。ミラージュドレッサーや愛蔵品キャビネットにある装備を組み合わせて作成します。登録したコーディネートをまとめて反映できるため、複数部位を一つずつ武具投影する手間を減らせます。
愛蔵品キャビネット特定の装備やイベント報酬などを保管できる専用収納。すべてのアイテムを収納できるわけではなく、対応しているアイテムだけが対象です。ミラージュプレートの見た目候補として利用できる対応品もあります。
HUDHP、ホットバー、マップ、パーティリストなど画面上の情報表示。HUDレイアウトでは各要素の位置・大きさ・表示状態を調整できます。画面解像度やプレイスタイルに合わせて、重要な情報を見やすい位置へ動かせます。
FC / フリーカンパニー同じワールドのプレイヤーで作る継続的なコミュニティ。所属は必須ではありません。FCチャットで交流できるほか、FCによってはカンパニーアクション、ハウジング、イベント、初心者支援などを利用・実施している場合があります。
LS / CWLS特定のメンバーで会話するためのグループチャット。LSは主に同じワールド内、CWLSはクロスワールドでメンバーと会話するために使います。FCとは違い、会話用のグループとして複数参加して使い分けられます。
マーケットボード他プレイヤーが出品したアイテムを検索・購入する市場機能。購入はマーケットボードから行い、自分が販売するときはリテイナーを通して出品します。同じアイテムでも出品価格は変動するため、NPC販売や自力入手の方が安い場合もあります。
グループポーズスクリーンショット撮影向けの専用モード。カメラ、ライト、被写界深度、エフェクトなどを調整して撮影できます。通常のゲーム画面より細かく構図を作れるため、キャラクターや風景の撮影でよく使われます。
ポートレートキャラクターの立ち姿や表情などを設定して作るプロフィール画像。対応コンテンツの開始時表示などに使われます。装備や見た目を変えた後は、設定したポートレートとの状態差によって更新が必要になる場合があります。
アドベンチャープレートキャラクターのプロフィールをまとめて見せるカード。ポートレート、プロフィール項目、プレイスタイルなどを組み合わせて自分の紹介用に設定できます。
IDインスタンスダンジョンの略称。専用のエリアへ移動して、決められた人数のパーティで道中の敵やボスを攻略するコンテンツを指します。FF14の会話や募集では「ID」と省略されることが多いです。
ILアイテムレベルの略称。装備の強さを示す数値です。キャラクターレベルとは別の数値で、同じ装備可能レベルでもILが高い装備ほど基本性能が高い傾向があります。コンテンツによっては平均アイテムレベルが参加条件になります。
CFコンテンツファインダーの略称。ダンジョンや討滅戦などを選んで参加申請し、必要なロールのプレイヤーを自動で探してパーティを組む機能です。
RFレイドファインダーの略称。対象となる高難度コンテンツへ参加申請するための機能です。通常のコンテンツファインダーとは対象コンテンツや申請条件が異なります。
MT / STタンク2人で役割を分けるときの呼び方。MTはメインタンク、STはサブタンクを指します。主に8人向けコンテンツなどで、どちらがボスを受け持つかを区別するときに使われます。
GCD複数のウェポンスキルや魔法で共有される基本の再使用待ち時間。GCD対象のアクションを使うと、ほかのGCD対象アクションも一定時間使えなくなります。戦闘ではこの待ち時間を基準にアクションをつないでいきます。
oGCDGCDとは別枠で使えるアビリティ類を指す通称。GCDの待ち時間中にも使えるアクションが多く、基本のウェポンスキルや魔法の間に組み合わせて使います。
AoE範囲攻撃・範囲効果を指す呼び方。複数の敵を同時に攻撃する技だけでなく、床に表示される敵の範囲攻撃や、一定範囲へ作用するギミックを指して使われることもあります。
DoT一定時間、継続してダメージを与える効果。一度付与すると、効果時間中に一定間隔でダメージが発生します。Damage over Timeの略称です。
HoT一定時間、継続してHPを回復する効果。一度付与すると、効果時間中に一定間隔で回復が発生します。Healing over Timeの略称です。
LBリミットブレイクの略称。パーティで共有するゲージを使って発動する特殊アクションです。ロールによって攻撃・回復・防御など効果が異なります。
ETエオルゼア時間の略称。ゲーム内世界の時刻です。採集・釣りなど、ゲーム内時刻によって出現条件が変わる要素でよく使われます。現実時間より速く進みます。
LTローカル時間の略称。自分の地域・端末側の時刻です。ゲーム内のエオルゼア時間とは別に、現実世界の現在時刻を確認するときに使われる表記です。
HQHigh Qualityの略称。高品質アイテムを表す表記です。対応するアイテムで通常品質とは別に高品質品が存在する場合、その区別として使われます。アイテムの種類によってHQの扱いは異なります。
NQ通常品質のアイテムを指す呼び方。HQと区別したいときにNormal Qualityの意味で使われます。ゲーム内で常にNQと表示されるわけではなく、プレイヤー間での呼び方として使われます。
CPクラフターが製作アクションに使うポイント。製作中に一部のアクションを使用すると消費します。使えるCP量によって組み立てられる製作手順が変わります。
GPギャザラーが採集アクションに使うポイント。採掘・園芸・漁師などで一部の採集アクションを使うと消費します。時間経過などで回復します。
シンクコンテンツに合わせてレベルや装備性能が調整される状態。低レベルのコンテンツへ参加したときなどに、本来のレベルや装備性能のままではなく、そのコンテンツに合わせた上限へ自動調整されます。
制限解除通常の参加条件の一部を外してコンテンツへ入る設定。主に過去コンテンツの攻略や周回で使われます。レベルシンクや人数など通常攻略時とは条件が変わるため、通常の攻略体験とは別の遊び方になります。
初見そのコンテンツをまだ体験・クリアしていない人を表す言い方。募集文などで「初見です」「初見歓迎」と書かれることがあります。初めて遊ぶ人がいることを事前に共有するための表現です。
MMO / MMORPG多数のプレイヤーが同じオンライン世界で遊ぶゲームの呼び方。MMORPGは、その中でもキャラクターを育てながら冒険するRPGを指します。FF14はMMORPGに分類されます。
PvEプレイヤーがゲーム側の敵やコンテンツを攻略する遊び方。ダンジョン、討滅戦、レイド、フィールドの敵との戦闘など、プレイヤー同士の対戦ではない戦闘コンテンツをまとめて指します。
PvPプレイヤー同士で対戦する遊び方。FF14ではPvP専用のルールやアクションを使うコンテンツがあり、通常のPvE戦闘とは操作や性能が異なる部分があります。
NPCプレイヤーが操作していないゲーム内キャラクター。クエストの依頼人、ショップ店員、ストーリーに登場する人物など、ゲーム側が動かしているキャラクターを指します。
PT / Party複数のプレイヤーで組むグループ。ダンジョンや討滅戦などの攻略、フィールドでの活動、募集などで利用します。会話では「PT」と略されることがあります。
野良 / PUG固定メンバーではなく、その場で集まったパーティ。コンテンツファインダーやパーティ募集などを使い、普段決まって一緒に遊んでいるメンバー以外と組む場合に使われる言い方です。
固定決まったメンバーで継続的に遊ぶグループ。特に高難度コンテンツなどで、曜日や時間を決めて同じメンバーで攻略を続けるグループを指すことが多いです。
Mobフィールドやダンジョンなどにいる一般的な敵を指す呼び方。MMORPGで広く使われる用語で、FF14でもボス以外の敵やフィールド上の敵などをまとめて指すときに使われます。
ヘイト / Aggro敵が誰を狙うかに関係する優先度を指す呼び方。FF14の正式な表現では「敵視」が使われます。パーティでは主にタンクが敵視を集め、敵の攻撃を引き受けます。
Buff自分や味方を有利にする強化効果。攻撃力上昇、ダメージ軽減、行動速度に関わる効果などをまとめてBuff／バフと呼ぶことがあります。
Debuff対象を不利にする弱体効果。能力低下、継続ダメージ、被ダメージ増加など、キャラクターへ不利な状態を与える効果をまとめて呼ぶ言葉です。
Cooldown / リキャストアクションを再び使えるようになるまでの待ち時間。使用後すぐに再使用できないアクションでは、次に使えるまでの残り時間が表示されます。プレイヤー間ではCooldownやCDという表現も使われます。
Loot / Drop敵や宝箱、コンテンツ報酬などから得られるアイテム。Lootは戦利品全般、Dropは敵などからアイテムが落ちることを指して使われることが多い言葉です。
Wipeパーティが全滅して戦闘をやり直すこと。特にボス戦や高難度コンテンツで、全員が戦闘不能になり、その戦闘を最初から再挑戦する状況を指します。
Respawn倒された敵やキャラクターなどが再び出現すること。フィールドの敵が一定時間後に再出現する場合などに使われる一般的なゲーム用語です。
Farm / 周回同じ敵やコンテンツを繰り返して報酬を集めること。装備、素材、マウントなど特定の報酬を目的に、同じコンテンツを何度も攻略するときに使われます。
