START

始めたばかりなら、メイン進行を止めない

FF14はレベルだけを先に上げても、メインクエストの進行によって開放される機能やコンテンツがあります。序盤は「経験値を取り切る」より、遊べる範囲を広げることを優先すると遠回りが減ります。

メインクエストを進める次の都市・機能・ダンジョンの開放を優先。
移動中のエーテライトを開放大きな寄り道をせず、次回の移動だけ短縮。
ジョブ関連クエストを節目で確認アクションやジョブ化に関係するものは後回しにしすぎない。
BATTLE

戦闘は技名より「予兆の形」を覚える

コンテンツごとの技名を全部暗記するより、何度も登場する共通パターンを先に覚える方が初見でも対応しやすくなります。

見た目基本対応
円・扇・直線範囲範囲のすぐ外へ。遠くへ逃げすぎない。
複数人へ個別マーカー味方と重ならない。
集合マーカー対象者付近へ集合。
視線系演出必要な瞬間だけ発生源へ背を向ける。
ノックバック飛ばされる先が安全になる位置へ。
優先順位は「死なない → 自分の役割 → 攻撃を止めない → 最適化」で十分です。
GEAR

装備は「更新できるか」ではなく「更新が必要か」

PRIORITY

武器を優先

影響が大きいので、明確に古い場合は最初に確認。

WAIT

すぐ報酬が来るなら待つ

数ポイントのために買い替えるより、次のクエスト報酬を利用。

TARGET

必要ILから逆算

次に行きたいコンテンツへ参加できるなら、無理に全身を更新しない。

TRAVEL

移動は1回のテレポ代より「往復回数」を減らす

最寄りへ直接テレポ

細かな節約より移動時間を優先。

都市内転送網を使う

大都市を徒歩で横断しない。

同じ地域の用事をまとめる

クエスト・買い物・採集を1回の移動にまとめる。

INVENTORY

所持品整理は「再取得しやすいか」で判断

種類判断
低レベル装備ミラプリ・再利用予定がなければ処分候補。
用途不明の一般素材再取得しやすいなら抱え込まない。
交換用アイテム交換先と上限を確認してカテゴリごとに整理。
高価・希少素材価値を確認してから保管・売却。
空きを最大化するより、「必要な物を探す時間」を減らす方を優先します。
UI / CONTROL

UIは自分が何度も見る場所から整える

最初からHUDを完璧に作る必要はありません。HP、ターゲット情報、パーティリスト、頻繁に使うアクションから順番に調整します。

自分向けの調整順

条件を選んでください。
ROUTINE

日課・週課は全部やらなくていい

「日課を消化する」こと自体を目的にせず、今欲しい経験値・通貨・装備・報酬につながるものだけ選びます。

時間が短い
1〜2個に絞る週制限や1回あたりの効率が高いものから。
欲しい報酬がない
その日課は飛ばす毎日全部やる必要はありません。
